# ADR-0001：采用 CLI + 单函数抽取的形态

- 状态：已接受
- 日期：2026-10-30
- 相关文件：docs/design.md、docs/contract.md

## 背景

需求是从发票文本抽取三个字段，调用频率低（个人每天几次），没有并发与多用户要求。需要在一天内验证提示词是否可行。

## 选项

| 选项 | 优点 | 缺点 | 成本 |
|---|---|---|---|
| A CLI + 单函数 | 最快验证，易单测，零部署 | 无服务化能力 | 0.5 天 |
| B MCP Server | 可被任意客户端复用 | 需处理传输、鉴权，验证慢 | 2 天 |
| C HTTP 服务 | 可对外提供 | 需部署、监控、运维 | 3 天 |

## 决策

选 A。当前唯一未知是抽取质量，不是接入方式。先用 CLI 把评测跑通，质量达标后再决定是否包成 MCP 工具。

## 后果

- 正面：当天可跑通链路，评测先行。
- 负面：暂时不能在其他客户端直接调用。
- 后续注意：如果调用方从“我自己”变成“多个工具”，再走 ADR 评估 MCP 形态。
- 重新评估触发条件：一周内使用超过 20 次，或需要被其他 agent 调用。

## 备注

形态选择参考上级规范 `docs/03-形态适配指南.md` 第 0 节。
